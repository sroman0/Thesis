This thesis presents the design and implementation of a security monitoring tool that collects and analyzes network connection data directly from the operating system kernel using \gls{ebpf}. By leveraging kernel-level instrumentation, the system captures detailed information about network activity with high accuracy and minimal overhead, overcoming the limitations of traditional user-space monitoring approaches.

The proposed tool adopts a modular and efficient architecture to ensure scalability and real-time data collection. The gathered data is structured to support security analysis, enabling the detection of anomalous behaviors such as suspicious outbound connections, unauthorized communication patterns, and potential data exfiltration attempts.

This work demonstrates how kernel-derived network telemetry, combined with \gls{ebpf} technology, can enhance system visibility and provide a solid foundation for advanced network security monitoring and threat detection.
